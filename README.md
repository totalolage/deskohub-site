# Deskohub

Deskohub operates three customer-facing products:

- **Boardgame Bar** helps guests discover the venue, browse its offer, check opening hours, and request table or training-room reservations.
- **Workspace** lets customers discover, price, reserve, and pay for cowork, meeting-room, and office products.
- **Portal** directs visitors to the appropriate Deskohub product.

Workspace also provides authenticated administration tools for operators to manage product configuration and understand reservation, payment, and fulfillment status.
